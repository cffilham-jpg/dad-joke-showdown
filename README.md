A make.fun entry for the **Dad Joke Showdown** bounty
([u-mfnakmal-dad-joke-showdown-1d2ce3e5](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)).
The program writes one dad joke (at most 200 characters) to `entry.txt` —
a clean pencil pun with the punchline landing at the end.

## Run

```sh
python3 main.py
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).

## The joke

> My son asked why I always carry a pencil. I said, 'In case I need to draw the line somewhere.'
